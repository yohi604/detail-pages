# Detail Flow · 상세페이지 스튜디오

이미지와 GIF를 순서대로 배치하고 긴 상세페이지를 만드는 정적 웹 편집기입니다. GitHub Pages에서 실행하며 ChatGPT를 열 필요가 없습니다.

- 이미지·GIF 여러 개 추가, 교체, 드래그 또는 버튼으로 순서 변경
- 숨김·삭제·실행 취소, 데스크톱·모바일 미리보기
- 여러 프로젝트 관리, 현재 브라우저 자동 저장
- 전체 상세페이지 HTML 다운로드, 편집용 JSON 백업·불러오기
- GitHub에 상세페이지를 게시하고 같은 링크에 수정본 반영

## 처음 열기

[편집기 주소](https://yohi604.github.io/detail-pages/)

저장소 **Settings → Pages → Deploy from a branch → main → /(root) → Save**로 설정합니다. 게시 완료 후 위 주소를 북마크하면 됩니다. 별도 서버·빌드는 필요 없습니다.

첫 화면은 빈 작업입니다. 필요한 이미지와 GIF를 직접 추가하세요. 기존 제품 이미지 원본은 이 저장소에 포함하지 않았습니다.

## 기존 작업 옮기기

기존 디테일 플로우 주소에서 **내보내기 → 편집용 백업 다운로드**를 누른 뒤, 새 주소에서 **내보내기 → 편집용 백업 불러오기**로 가져옵니다. 주소가 바뀌면 브라우저 저장 공간이 달라지므로 자동으로 이동하지 않습니다.

## 상세페이지 링크 게시

편집·미리보기·백업에는 토큰이 필요 없습니다. 앱에서 GitHub에 새 상세페이지를 게시하거나 수정본을 올릴 때만 GitHub 쓰기 권한이 필요합니다.

1. GitHub의 Fine-grained personal access token에서 `yohi604/detail-pages`만 선택합니다.
2. `Contents: Read and write`, `Pages: Read-only` 권한을 부여합니다.
3. 편집기의 **GitHub 연결**에 토큰을 입력합니다.
4. **게시 · 공유 → 페이지 게시하기**를 누릅니다.
5. Pages 반영 상태를 확인하고 공유 주소를 복사합니다.

토큰은 해당 탭의 메모리에만 유지되며 GitHub API에만 전송됩니다. 새로고침·탭 닫기 후 다시 입력해야 합니다. 소스·백업·브라우저 저장소에 토큰을 저장하지 않습니다. ChatGPT의 GitHub 연결은 이 독립 웹 앱에 자동으로 전달되지 않습니다.

게시된 뷰어는 `details/<프로젝트 ID>/`에 저장됩니다. 방문자는 이미지와 GIF만 볼 수 있으며 편집할 수 없습니다. 에디터 화면은 누구나 열 수 있지만, 다른 방문자의 편집은 그 방문자의 브라우저에만 저장됩니다. 이 저장소의 게시 내용을 바꾸려면 GitHub 쓰기 권한이 필요합니다.

## 저장과 공개 범위

- 편집 작업은 현재 브라우저의 IndexedDB에 저장됩니다. 기기를 바꾸기 전 편집용 백업을 다운로드하세요.
- HTML 다운로드와 전체 미리보기는 자동으로 온라인에 공개되지 않습니다.
- **게시**를 실행하면 이미지 원본과 프로젝트 정보가 공개 GitHub 저장소에 올라갑니다. 숨김 이미지는 화면에서만 제외되며 원본은 저장소에 남습니다.
- 토큰 만료·연결 해제 후에도 이미 게시된 링크는 유지됩니다.
- 브라우저 작업 삭제는 이미 게시된 페이지를 삭제하지 않습니다.
- GIF는 다른 형식으로 변환하지 않고 원본을 유지합니다.

기본 제한은 파일당 50 MiB, 프로젝트당 400 MiB, 300개입니다. GitHub 서비스 한도는 별도로 적용됩니다.

## 소스 구성

- `index.html`, `style.css`, `app.js`: 편집 화면·파일 처리·저장·미리보기·백업
- `github.js`: GitHub 연결·원자적 커밋·Pages 상태·원격 프로젝트 불러오기
- `sample.json`: 빈 초기 프로젝트
- `.nojekyll`: 정적 파일을 그대로 제공

`file://`로 직접 여는 방식은 지원하지 않습니다. 로컬 확인은 `python3 -m http.server 8000`으로 실행한 뒤 `http://localhost:8000/`을 엽니다.

에디터를 업데이트할 때 기존 `details/` 폴더는 유지해야 합니다. 프로젝트 게시 기능은 해당 프로젝트 폴더만 갱신하며 에디터 소스를 덮어쓰지 않습니다.

## 확인 범위

기존 편집기에서 이미지·GIF 표시, 순서 변경, 숨김·실행 취소, 모바일 미리보기, 업로드·새로고침 후 복원을 확인했습니다. GitHub Pages 이전본은 JavaScript 구문과 상대 경로를 확인했습니다. 사용자의 전용 토큰으로 앱에서 직접 게시하는 과정은 별도 확인이 필요합니다.
